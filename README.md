# 😊 Real-Time Facial Emotion Detection App

A **real-time facial emotion detection application** using computer vision and machine learning.  
The app detects faces, extracts facial landmarks, and classifies emotions via an SVM model.

---

## 🚀 Features

- 🎥 Real-time webcam emotion detection
- 🧠 68 facial landmarks using **dlib**
- 🤖 SVM-based emotion classification
- 🖥️ Interactive Streamlit web interface

---

## 🧩 Tech Stack

- Python
- OpenCV
- dlib
- Scikit-learn
- Streamlit

---

## 📌 Use Case

Demonstrates the fundamentals of:
- Computer Vision
- Facial feature extraction
- ML-based emotion classification
