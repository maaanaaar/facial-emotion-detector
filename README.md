# 🎭 Real-Time Facial Emotion Detection App

A simple **real-time emotion detection app** built using **OpenCV, dlib, and Streamlit**.  
The app detects faces, extracts 68 facial landmarks, computes feature distances, and classifies emotions using an SVM model.

---

## 🚀 Features
- Real-time emotion detection via webcam  
- Uses dlib’s 68 facial landmarks  
- SVM model trained on synthetic data (for demonstration)  
- Interactive Streamlit web interface  

---

## 🧠 Tech Stack
- **Python**
- **OpenCV**
- **dlib**
- **scikit-learn**
- **Streamlit**
